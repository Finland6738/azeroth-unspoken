Azeroth Unspoken: commands (the command names are always in English, whatever the interface language):
Azeroth Unspoken: /au help [<group> / <command> / all] - the command groups; /au help <group> lists a group, /au help <command> explains one
Azeroth Unspoken: /au on / off - enable or disable automatic lines
Azeroth Unspoken: /au pause - pause the narrator immediately (also with the bound key)
Azeroth Unspoken: /au language [it / en] - phrase and interface language
Azeroth Unspoken: /au literary never / rare / normal - how often verses, songs and tales come (private narrator only)
Azeroth Unspoken: /au options - open the settings panel
Azeroth Unspoken: /au wizard - redo the first-run guide
Azeroth Unspoken: /au intensity <0-100> - how often the narrator speaks up
Azeroth Unspoken: /au depth natural / literary / elevated - how elevated the style is
Azeroth Unspoken: /au narrator [history / reset / clear] - the narrator box
Azeroth Unspoken: /au greet / farewell / toast / muse / threat / battlecry / victory / pray / thanks / jest [target] - propose a line for that moment (a name or target is optional)
Azeroth Unspoken: /au event <name> - propose a line for an event (battle, zone, muse...)
Azeroth Unspoken: /au cast <spell> - a line for a spell (handy in macros)
Azeroth Unspoken: /au chance <event> <0-100> - probability of an event
Azeroth Unspoken: /au cooldown <seconds> - pause between automatic lines
Azeroth Unspoken: /au ignore <spell> - never comment on a spell (again to undo)
Azeroth Unspoken: /au mode private / preview / confirm / auto - what may reach chat (default: private; auto asks for confirmation)
Azeroth Unspoken: /au channel auto / say / emote / party / raid / guild / instance / next - default chat channel; next: the channel of the waiting proposal
Azeroth Unspoken: /au speak - confirm the waiting proposal (also from a macro or key)
Azeroth Unspoken: /au another - swap the pending proposal for another line (sends nothing)
Azeroth Unspoken: /au cancel - discard the proposal
Azeroth Unspoken: /au copy - copy the proposal into the chat box (you send it with Enter)
Azeroth Unspoken: /au trp3 [ooc on/off / markup on/off] - Total RP 3 etiquette: stay private while out of character (ooc), write emotes outside /e as *action* (markup)
Azeroth Unspoken: /au combat show / chat / hold / silent - what the narrator does during a fight
Azeroth Unspoken: /au button [on / off / editor on/off / reset] - show, hide or reset the speak button; editor on: a click opens the editor instead of sending
Azeroth Unspoken: /au soul [list / neutral / archetype <id> / trp3 on/off / <trait> <value> / avoid <topic> / culture <culture>] - character personality
Azeroth Unspoken: /au emotion [on / off / reset] - the character's emotional state: show, switch on or off, reset
Azeroth Unspoken: /au journal [list / places / flag <name> / export / pin <n> / delete <n> / forget <place> / reset] - character memory and journal
Azeroth Unspoken: /au songbook [list / reset] - the songbook: verses and songs heard, their marks
Azeroth Unspoken: /au stories [list / journal / choose <arc> <option> / start / suspend / resume / skip / disable / enable <arc/all> / max <1/2> / on / off / status] - the character's personal stories
Azeroth Unspoken: /au relationships [list / people / add <name> / note <name> <text> / export / ...] - relationships with NPCs and players (short form: rel)
Azeroth Unspoken: /au place - where you are: zone, map, tags, territory, instance (to check the place data)
Azeroth Unspoken: /au who [trp3 on/off / trait <trait> <value>] - who is in front of you: role, personality, recent actions
Azeroth Unspoken: /au talk [test [style] / close / role <role> / offer on/off / status] - ambient dialogue with the NPC in front of you
Azeroth Unspoken: /au debug [full / trace] - diagnostics: client capabilities, recent events, errors
Azeroth Unspoken: /au prof [reset / copy] - profiling of this session: timings, memory, Director counters (reset / copy)
Azeroth Unspoken: /au probe [reset / stop / copy] - probe the client APIs the next features need and report which work (reset / stop / copy)
Azeroth Unspoken: /au test <event> - preview a line in the local chat
Azeroth Unspoken: /au packs - list the phrase packs
Azeroth Unspoken: /au pack <id> on/off - turn a phrase pack on or off
Azeroth Unspoken: /au validate [full / <pack>] - check the phrase packs (errors and warnings)
Azeroth Unspoken: /au stats - how many lines are available
Azeroth Unspoken: /au memory - clear the anti-repetition memory
