# Content need

Generated by `python tools/archive/cli.py need --write` from the model `tools/archive/need_model.json` ([ADR 0050](../adr/0050-need-model-near-duplicates-and-content-waves.md)); do not edit by hand. The machine-readable report is [need.json](need.json); the plan of the waves is [WAVES.md](WAVES.md).

**Need** = how many distinct texts per language a pool must hold so that no character hears one of its texts twice in **400 hours** of play (strict) or in any **40 hours** in a row (soft), at the default pace of **22.5** interventions per hour and the default depth `literary`. It assumes an anti-repetition that exhausts a pool before repeating (see the ADR: today's engine keeps a window of 30 picks per event). Counted state: `approved`.
